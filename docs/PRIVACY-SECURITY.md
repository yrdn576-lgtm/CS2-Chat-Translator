# Privacy and security

## What the application does

CS2 Chat Translator reads supported local CS2 chat log output, sends text requiring translation to the DeepL API, and displays translated messages in a local overlay.

## Data and third parties

Chat text submitted for translation is transmitted to DeepL. DeepL's applicable privacy policy, service terms, and API plan govern its processing. Review [DeepL's privacy information](https://www.deepl.com/privacy) before using the service.

The application uses your own DeepL API credentials. Do not share your key or paste it into public support requests. Local settings may be retained between application launches; avoid sharing application data folders without reviewing their contents.

**Not independently audited:** No independent security or privacy audit is claimed here. This document describes intended functionality and should not be read as a guarantee that no diagnostic or other data is ever generated.

## Distribution and integrity

The v1.0.0 tester archive was built for Windows x64 and is not digitally signed. Verify its SHA-256 before use. Never disable antivirus or operating-system protections as a workaround.

The initial release uses manual updates. Only download new versions from verified project release channels.

## Responsible bug reports

Use [GitHub Issues](https://github.com/yrdn576-lgtm/CS2-Chat-Translator/issues/new) or [Discord](https://discord.gg/ExnAs6qP83). Do not publish API keys, tokens, private messages, or unredacted logs.
